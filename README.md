# Temperature Conversion 🌡️ 

## Description
This is a simple Python program that converts temperatures between **Celsius**, **Fahrenheit**, and **Kelvin**. The user is prompted to input a temperature value and its unit of measurement, and the program calculates and displays the equivalent values in the other two units.

## Features
- Supports conversion between:
  - Celsius to Fahrenheit & Kelvin
  - Fahrenheit to Celsius & Kelvin
  - Kelvin to Celsius & Fahrenheit
- User-friendly input and output
- Clear and accurate temperature conversion formulas

## How It Works
1. The program asks the user to enter a temperature value.
2. The user specifies the original unit (`Celsius(C)`, `Fahrenheit(F)`, or `Kelvin(K)`).
3. The program calculates and displays the converted values in the other two units.

## Program Preview
```plaintext
Enter the temperature value: 25
Enter the unit (C, F, K): C
25.0°C is 77.00°F and 298.15K
```
